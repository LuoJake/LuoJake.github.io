# Jake 的文字花园

一个部署在 GitHub Pages 上的个人文字库，包含阅读、搜索、标签归档、文章详情、可视化写作台和旧文字批量识别。

## 本地预览

在项目目录运行：

```powershell
python -m http.server 4173
```

然后打开终端显示的本地地址。网站使用 CDN 加载 Markdown 渲染器、图标和可视化编辑器，首次打开需要联网。

## 内容管理

- 示例公开内容位于 `js/content.js`。
- 写作台草稿保存在当前浏览器的 `localStorage` 中，不会自动公开。
- 写作台可以导出带元信息的 Markdown 文件，后续可由导入脚本转换为公开内容。
- 大量旧文字可以在写作台中按空行、日期或每行一条进行初步拆分，再存为待整理草稿。

## 发布

仓库连接 GitHub 后，可在仓库 Settings > Pages 中选择 `main` 分支根目录进行发布。

## 内容来源说明

站内英文短引文均保持较短，并在文章末尾提供出处。中文内容包含翻译和整理，不应被视为官方译文。正式扩充内容时应继续保留来源字段，并避免使用无法核实的网络语录。
